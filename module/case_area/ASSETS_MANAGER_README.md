# Case Fun Box - 套件庫管理功能

## 功能說明

在 `case_fun_box.php` 中已整合資產管理功能，讓您可以直接在功能區塊管理頁面中快速選擇和管理套件。

## 使用步驟

### 1. 打開套件庫管理
- 點擊左側功能區塊面板中的 **「套件庫」** 按鈕（黃色按鈕）
- 系統會開啟資產管理 Modal 視窗

### 2. 套件庫標籤 (Library Tab)
在這個標籤中，您可以：
- **瀏覽所有可用的套件**
- **按分類篩選**：使用下拉菜單篩選不同的套件分類（jQuery、Bootstrap、Font Awesome 等）
- **選擇套件**：勾選復選框以選擇要應用的套件
- **查看套件信息**：
  - 套件名稱和類型（JS/CSS）
  - 文件路徑
  - 版本號
  - 描述信息

### 3. 自訂資源標籤 (Custom Assets Tab)
在這個標籤中，您可以：
- **新增自訂資源**：點擊「新增自訂資源」按鈕
- **管理現有自訂資源**：
  - **預覽**：查看資源的程式碼內容
  - **編輯**：修改資源配置和內容
  - **啟用/停用**：控制資源是否在頁面中加載
  - **刪除**：移除不需要的自訂資源

### 4. 新增/編輯自訂資源
填寫以下信息：
- **資源名稱**：為資源設置一個有意義的名稱
- **資源類型**：選擇 JavaScript 或 CSS
- **載入位置**：
  - `Head`：在頁面 `<head>` 標籤中載入（通常用於 CSS）
  - `Body Top`：在 `<body>` 開始時載入
  - `Body Bottom`：在 `</body>` 前載入（通常用於 JS）
- **載入順序**：數字越小越優先載入（默認 200）
- **程式碼內容**：貼上您的 CSS 或 JavaScript 代碼

### 5. 儲存設定
完成選擇後，點擊 **「儲存設定」** 按鈕保存所有更改。

## 技術細節

### 文件路徑
- 主文件：`/module/case_area/case_fun_box.php`
- 資產管理 AJAX 處理：
  - `/module/assets_manager/ajax_handler.php` - 案件級資源管理
  - `/module/assets_manager/library_ajax.php` - 套件庫管理

### 存儲位置
- 選中的套件信息存儲在 `case_assets` 數據表中
- 自訂資源存儲在 `custom_assets` 數據表中

### API 端點

#### 套件庫相關
- **get_library_assets** - 獲取可用套件列表
- **get_categories** - 獲取套件分類列表

#### 自訂資源相關
- **get_custom_assets** - 獲取自訂資源列表
- **save_custom_asset** - 保存自訂資源
- **delete_custom_asset** - 刪除自訂資源
- **toggle_custom_asset** - 切換自訂資源狀態

#### 案件資源相關
- **save_case_assets** - 保存案件選定的套件

## 注意事項

1. **資源衝突**：避免重複選擇相同的套件庫資源
2. **加載順序**：自訂資源的加載順序很重要，特別是有依賴關係時
3. **備份**：修改自訂資源前建議先備份內容
4. **瀏覽器兼容性**：複雜的自訂代碼需確保與目標瀏覽器相容
5. **測試**：在正式發佈前務必在預覽中測試新增的資源

## 常見問題

### Q: 如何快速應用常用套件組合？
A: 使用分類篩選功能快速定位，或在套件庫管理頁面預先建立常用組合。

### Q: 自訂資源沒有生效？
A: 檢查：
1. 資源是否已啟用（綠色狀態）
2. 代碼語法是否正確
3. 頁面是否正確刷新

### Q: 如何更改資源的加載位置？
A: 點擊編輯按鈕，修改「載入位置」下拉菜單並保存。

### Q: 可以同時應用 JavaScript 和 CSS 嗎？
A: 可以。系統支持同時應用多個 JavaScript 和 CSS 資源。
